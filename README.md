A compact Python chess engine in 4 KB that plays the make.fun tiny-chess-01 gauntlet: alpha-beta search with quiescence, a transposition table and piece-square evaluation, packed to fit 4,096 bytes.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
